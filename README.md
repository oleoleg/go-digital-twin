# Digital Twin Satellite Backend (Go + PostgreSQL)

Прототип бэкенд-платформы для сбора телеметрии цифрового двойника низкоорбитальной спутниковой группировки. Проект разработан при помощи ИИ в обучающих целях на языке Go с интеграцией высоконагруженной СУБД PostgreSQL.

## 🚀 Функционал 
- **Имитация датчиков:** Генерация случайных показателей телеметрии с обработкой возможных сбоев связи (Fail Fast).
- **Конкурентный сбор:** Параллельный опрос модулей через горутины и каналы с контролем таймаутов (`select`).
- **Персистентность данных:** Запись логов в PostgreSQL через производительный драйвер `pgx`.
- **Безопасность конфигурации:** Все секреты и доступы к СУБД вынесены в изолированные переменные окружения через `.env`.
- **Интерфейс мониторинга:** Легкий футуристичный HTML/CSS дашборд оператора ЦУП с мгновенной скоростью загрузки и автоматической подсветкой перегревов модулей.

## 🛠️ Стек технологий
- **Язык:** Go 1.21+
- **СУБД:** PostgreSQL 16/17
- **Библиотеки:** `jackc/pgx/v5`, `joho/godotenv`

## 📦 Быстрый старт

### 1. Подготовка конфигурации
Создайте файл `.env` в корне проекта и укажите параметры подключения к вашей СУБД:
```text
DATABASE_URL=postgres://postgres:ваш_пароль@localhost:5432/digital_twin?sslmode=disable
```

### 2. Запуск локально
Убедитесь, что PostgreSQL запущен, и выполните команду в терминале:
```bash
go run main.go
```
После запуска панель будет доступна по адресу: `http://localhost:8080/`

### 3. API Эндпоинты
- `GET http://localhost:8080/save` — сгенерировать и записать лог датчика в СУБД.
- `GET http://localhost:8080/history` — получить последние 10 записей из базы данных в формате JSON.
- и др.


## 🧪 Тестирование и Производительность

Проект покрыт идиоматическими тестами стандартной библиотеки Go:
- **Table-Driven Tests:** Проверка граничных температурных состояний датчиков в единой таблице сценариев.
- **Benchmark Tests:** Замеры скорости выполнения критических участков кода и аллокации памяти.

### Запуск тестов и проверка покрытия (Coverage):
```bash
go test -v -cover
```

### Запуск бенчмарков производительности памяти и процессора:
```bash
go test -bench=. -benchmem
```
