# Digital Twin Satellite Backend (Go + PostgreSQL)

Прототип бэкенд-платформы для сбора телеметрии цифрового двойника низкоорбитальной спутниковой группировки. Проект разработан при помощи ИИ в обучающих целях на языке Go с интеграцией высоконагруженной СУБД PostgreSQL.

## 🚀 Функционал
- **Имитация датчиков:** Генерация случайных показателей телеметрии с обработкой возможных сбоев связи (Fail Fast).
- **Конкурентный сбор:** Параллельный опрос модулей через горутины и каналы с контролем таймаутов (`select`).
- **Персистентность данных:** Запись логов в PostgreSQL через производительный драйвер `pgx`.

## 🛠️ Стек технологий
- **Язык:** Go 1.21+
- **СУБД:** PostgreSQL 16/17
- **Драйвер БД:** `jackc/pgx/v5`

## 📦 Быстрый старт

### 1. Подготовка Базы Данных
Создайте базу данных `digital_twin` в PostgreSQL и выполните миграцию (таблица `sensor_logs` создается автоматически при первом запуске приложения).

### 2. Запуск локально
Убедитесь, что вы прописали ваш пароль от БД в `main.go`, и выполните:
```bash
go run main.go
```

### 3. API Эндпоинты
- `GET http://localhost:8080/save` — сгенерировать и записать лог датчика в СУБД.
- `GET http://localhost:8080/history` — получить последние 10 записей из базы данных в формате JSON.
